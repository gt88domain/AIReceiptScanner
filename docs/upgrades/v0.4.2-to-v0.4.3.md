# Upgrade from v0.4.2 to v0.4.3

v0.4.3 makes `jobs: false` a supported production mode and adds the
`directory-lite` profile. Existing `directory` and all existing direct
configuration remain Jobs-on; no downstream repository changes automatically.

Adopt only on a dedicated branch. First get a read-only assessment:

```bash
git checkout main
git pull --ff-only
git fetch template --tags
git checkout -b chore/adopt-easystarter-v043

pnpm template:upgrade-check --from v0.4.2 --to v0.4.3 --profile directory-lite
```

For a Jobs-off product, deliberately remove its Queue producer, Queue/DLQ
consumers, Cron trigger, and `JOB_QUEUE_DLQ_NAME` from its own Wrangler
configuration. Do not run migrations, remove historical Jobs tables, create or
delete Cloudflare resources, or hand-edit `routeTree.gen.ts`. Then set the
product feature contract to `jobs: false`, run checks, and open a Draft PR.

The upgrade checker is read-only: it does not change files, manifests, cloud
resources, SQL, Git history, or deployments. Keep migration work separate from
this adoption.
