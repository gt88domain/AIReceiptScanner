# Upgrade from v0.4.0 to v0.4.5

v0.4.5 completes optional runtime composition for Jobs, Storage, Email, Billing,
and Credits. It adds no schema changes, no migration changes, no Cloudflare
resources, and no automatic downstream updates.

Adopt on a dedicated branch. First run the read-only assessment, then merge the
released tag only after reviewing protected-path overlap:

```bash
git checkout main
git pull --ff-only
git fetch template --tags
git checkout -b chore/adopt-easystarter-v045

pnpm template:upgrade-check --from v0.4.0 --to v0.4.5
```

Set the product feature contract deliberately. Billing requires Jobs; Web credit
purchases require both Web Credits and Web Billing. Jobs-off products must remove
their own Queue producer, Queue/DLQ consumers, Cron trigger, and
`JOB_QUEUE_DLQ_NAME` from their own Wrangler configuration. Billing-off products
must remove their own payment webhook routes and provider secrets. Storage-off
products may remove R2 bindings. Do not mock a disabled binding.

Use `directory-lite` only for a Jobs-off directory/content product. Existing
`directory` remains Jobs-on. Existing historic Jobs, Billing, and Credits tables
are not deleted: disabled capabilities simply do not initialize their services,
register their runtime routes, or access their tables.

Before opening a Draft adoption PR, run:

```bash
pnpm profiles:check
pnpm profiles:build
pnpm test:template
pnpm test:integration
```

`profiles:build` is local build proof only. It uses temporary output, never
deploys, changes no Cloudflare resource, and leaves no generated profile overlay
in the repository. Do not run migrations automatically, hand-edit
`routeTree.gen.ts`, create queues, or deploy as part of the upstream adoption.
