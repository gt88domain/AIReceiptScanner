# Upgrade from v0.4.0 to v0.4.1

v0.4.1 adds Product Profiles, feature-aware production preflight checks,
non-deployable Wrangler examples, and a read-only downstream upgrade check.
It does not add database migrations, alter existing routers or request context,
physically remove Jobs, generate Wrangler files, or update downstream projects.

If a downstream repository does not adopt v0.4.1, nothing changes.

To adopt it, create a dedicated branch and assess the released tag before a
merge:

```bash
git checkout main
git pull --ff-only
git fetch template --tags
git checkout -b chore/adopt-easystarter-v041

pnpm template:upgrade-check --from v0.4.0 --to v0.4.1
git merge --no-ff v0.4.1
```

Resolve conflicts deliberately. Do not run migrations automatically. After the
merge, run the normal checks, update `.template/source.json` with the adopted
tag and commit, open a Draft PR, review it, and merge it without deploying as
part of the adoption.

The checker is strictly read-only: it does not fetch, merge, rebase, change
the manifest, install dependencies, modify a lockfile, run migrations, or
deploy. It returns exit code 0 for low/medium risk, 2 for high risk, and 3 for
blocked risk. A migration change on both sides is blocked and requires manual
history review.
