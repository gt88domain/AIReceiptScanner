Start the isolated preview with `pnpm preview:backoffice`, sign in with the account printed in the terminal, then record observations below. This is product acceptance, not a request to change the information architecture during the session.

## Checks

- ☐ Ordinary user cannot open `/admin/*`.
- ☐ Administrator can open every `/admin/*` page.
- ☐ No page calls a real email or payment provider.
- ☐ Billing, customer portal, upgrade, and credit-purchase actions show the preview block rather than opening an external provider.
- ☐ Record UX issues only; do not change navigation, Central, or downstream projects in v0.9.0.

## Explicitly out of scope

- New features or information architecture changes
- Central Control and all downstream repositories
- Deployment, Zero Trust, real provider credentials, and real payment/email smoke tests
- Analytics implementation or data-model changes
