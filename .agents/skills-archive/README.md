# Dormant repository skills

These skills are intentionally outside `.agents/skills`, so they are not
always-active repository instructions. They are retained for rollback and
specialized reference work.

- `external/` contains generic vendor/framework guidance that is not specific
  to EasyStarter's current boundaries.
- `overlapping-easystarter/` contains narrow walkthroughs already covered by an
  active EasyStarter skill or current operating documentation.

Do not edit archived guidance as if it were current policy. To reactivate a
skill, move its complete directory back to `.agents/skills` in a focused change
and explain the distinct task boundary in `docs/tooling-governance.md`.
