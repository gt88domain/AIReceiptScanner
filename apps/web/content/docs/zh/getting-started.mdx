## 前置条件

开始之前，请确保已安装以下工具：

- **Node.js** 20+
- **pnpm** 9+
- **Git**

## 快速开始

### 1. 克隆仓库

```bash
git clone https://github.com/your-username/easysaas.git
cd easysaas
```

### 2. 安装依赖

```bash
pnpm install
```

### 3. 设置环境

运行一键设置脚本：

```bash
pnpm run setup
```

这将自动配置 web 和 server 环境。

### 4. 启动开发

```bash
pnpm dev
```

应用将在以下地址可用：

| 应用   | 地址                  |
| ------ | --------------------- |
| Web    | http://localhost:3000 |
| Server | http://localhost:3001 |

## 可用脚本

| 脚本               | 说明                     |
| ------------------ | ------------------------ |
| `pnpm dev`         | 启动所有应用（开发模式） |
| `pnpm dev:web`     | 仅启动 Web               |
| `pnpm dev:server`  | 仅启动 Server            |
| `pnpm build`       | 构建所有应用             |
| `pnpm check-types` | TypeScript 类型检查      |
| `pnpm lint`        | 代码检查（`oxlint`）     |
| `pnpm fmt:check`   | 格式检查（`oxfmt`）      |

## 数据库设置

```bash
# 从 schema 生成迁移
pnpm db:generate

# 推送 schema 到 D1（开发环境）
pnpm db:push

# 打开 Drizzle Studio
pnpm db:studio
```
