# Full SaaS profile

Use this profile for subscription, Credits, asset-upload, or AI products. It needs D1, R2, a Queue with DLQ, and a Cron trigger. Configure one enabled web payment provider plus `BETTER_AUTH_SECRET`, `ADMIN_EMAILS`, and the matching production safety files before deployment.

These files are examples only. Copy and edit them deliberately; they contain non-deployable placeholders and do not create resources.
