# Security policy

Do not report vulnerabilities through public issues. Use GitHub's private
security-advisory reporting for `gt88domain/easystarter-template`, or contact
the repository owner privately with the affected path, impact, reproduction,
and any safe mitigation.

Do not include credentials, production URLs with tokens, customer data, or
exploit payloads in a report. Maintainers will acknowledge a report, assess
severity, and coordinate a fix before public disclosure.
