# EasyStarter governance pointer

[`AGENTS.md`](AGENTS.md) is the sole normative repository instruction source
for contributors and coding agents. This file intentionally does not repeat
ownership, testing, release, or production rules.

Use these non-normative operating references as needed:

- [Template governance](docs/template-governance.md): ownership and release
  rationale.
- [Architecture boundaries](docs/architecture-boundaries.md): dependency and
  runtime boundaries.
- [Tooling governance](docs/tooling-governance.md): retained automation and the
  object guarded by each script.
- [Upstream sync](docs/upstream-sync.md): downstream update and rollback flow.

When a reference conflicts with `AGENTS.md`, follow `AGENTS.md` and repair the
stale reference in a focused change.
